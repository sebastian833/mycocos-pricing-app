# App de pricing multi‑marca (MyCOCOS · MyHUEVOS · MENNT)

Aplicación web interna (Next.js) para ver el histórico de ventas, calcular precios por tipo de oferta y armar/evaluar packs.

- **Guía completa para trabajar en el proyecto:** [`CLAUDE.md`](./CLAUDE.md) y la carpeta [`docs/`](./docs).
- Producción: https://mycocos-pricing-app.vercel.app

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
